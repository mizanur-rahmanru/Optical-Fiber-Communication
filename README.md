# 🔬 Optical Fiber Communication Lab

> MATLAB-based laboratory experiments and simulations for **Optical Fiber Communication**.

---

## 📖 About The Project

This repository contains MATLAB programs developed for the **Optical Fiber Communication Laboratory** course.

The experiments demonstrate different concepts related to optical fiber communication through MATLAB-based calculations, simulations, and graphical analysis.

The main goal of this repository is to provide a collection of organized MATLAB scripts that can be used for **laboratory work, experimentation, analysis, and academic reference**.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/mizanur-rahmanru/Optical-Fiber-Communication.git
```

### 2. Navigate to the Project Directory

```bash
cd Optical-Fiber-Communication
```

### 3. Open MATLAB

Open MATLAB and set the cloned repository folder as the **Current Folder**.

### 4. Run an Experiment

Open any `.m` file and click **Run**.

For example:

```matlab
exp_1
```

or:

```matlab
exp_5
```
